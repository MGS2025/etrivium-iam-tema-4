# ETRIVIUM IAM — Tema 4

**El Reglamento Orgánico del Gobierno y de la Administración del Ayuntamiento de Madrid, de 31 de mayo de 2004 (II): Los Distritos: Disposiciones Generales. El Concejal Presidente. Estructura administrativa.**

Material de estudio para la oposición **C1 — Técnico Auxiliar TIC del Ayuntamiento de Madrid** (temario BOAM 10.032).

## Contenido

- **`index.html`** — web autosuficiente (offline) con 7 pestañas: Inicio, Contenido, Diagramas, Test, Casos, Validación y Fuentes. Motor de test con corrección automática y penalización 1/3.
- **`tema-4-indice.md`** — índice y datos clave.
- **`tema-4-contenido.md`** — contenido teórico (14 secciones) + los 21 distritos.
- **`tema-4-diagramas.md`** — 12 diagramas SVG.
- **`tema-4-test.md`** — 150 preguntas tipo examen + 20 pedagógicas.
- **`tema-4-caso-practico.md`** — 6 casos prácticos.
- **`tema-4-fuentes.md`** — registro normativo.
- **`tema-4-validacion.md`** — checklist de validación (María / Ana).
- **`tema-4-changelog.md`** — historial de versiones.

## Estado

**v1.0 — Pendiente de validación** por el IAM (María / Ana).

El `index.html` se **genera** a partir de los `.md` con `build_t4.py`. Editar los `.md` y volver a ejecutar el generador.
